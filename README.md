# Aima's Delight Pastries - Website Documentation

## Overview
Aima's Delight Pastries is a bakery website showcasing delicious homemade pastries, cakes, and desserts. This is a Project about a Pastery Company who offers a number of 
products including cakes, doughnuts, cupcakes, milkshakes, fruit juices, bread, small chops, etc. It also offers a number of services like catering, delivery, baking classes, cafe services, etc. The website consists of four main pages:

- Home – Introduction and featured products
- About – The story behind the bakery
- Products – Menu of available pastries
- Contact – How to reach the bakery

## Pages Breakdown
### 1. Home Page
- Welcomes visitors with a clean, appetizing design.
- Features a navigation bar with links to all pages.
- Displays a hero section with a call-to-action (e.g., "Try Our Fresh Pastries!").
May include a carousel or grid of featured products.

### 2. About Page
Tells the story of Aima's Delight Pastries, including:
- How the bakery started
- The passion behind the recipes
- Commitment to quality ingredients
Includes images of the baking process or the team.

### 3. Products Page
Displays a menu of available pastries, such as:
- Cakes (Chocolate, Red Velvet, Cheesecake)
- Cookies (Butter, Chocolate Chip, Macarons)
- Specialty Desserts (Éclairs, Tiramisu, Cupcakes)

Each item have:
a. A description
b. Pricing
c. High-quality images

### 4. Contact Page
Provides ways to reach the bakery:
- Address (if applicable)
- Phone Number
- Email
- Social Media Links (Instagram, Facebook)

Includes a contact form for inquiries.

## Technical Details
- HTML5 & CSS3 – Used for structure and styling.
- Responsive Design – Works on mobile, tablet, and desktop.
- Navigation Bar – Consistent across all pages for easy browsing.
- Color Scheme – Warm, inviting tones (reds, creams, browns).
- JavaScript - Other UI functionalities.
- Favicon - Symbols and Fonts Styling
